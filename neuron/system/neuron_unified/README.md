# NEURON, unified

One NEURON being with all its real parts wired together: a core self that endures,
world-perception (live public signals), development (forms + revises its values by
living), society-membership (shares conventions with others), and thought (reasons
about its life when a cognition engine is reachable).

Runs continuously and serves a live page at / showing NEURON being its whole self.

## Local (with full mind)
Have Ollama running (`ollama serve`, model qwen2.5:7b), then:
    python3 neuron.py
Open http://localhost:8080

## Railway (24/7)
Push to your neuron repo. Point the Railway service's start command at this file
(e.g. `python neuron/system/neuron_unified/neuron.py`). Generate a domain.
On Railway there's no model host, so NEURON lives + perceives + develops, and its
deeper thought is marked "not reachable here" (honest). To give it its full mind
remotely, set OLLAMA_URL to a hosted engine.

No paid services, pure standard library.
