```python
def median(values):
    sorted_values = sorted(values)
    n = len(sorted_values)
    mid = n // 2
    if n % 2 == 0:
        return (sorted_values[mid - 1] + sorted_values[mid]) / 2
    else:
        return sorted_values[mid]
```
PR_BODY: This function calculates the median of a list of values. It first sorts the list, then checks if the number of elements is odd or even. If odd, it returns the middle element. If even, it returns the average of the two middle elements.
